# रक्त Donor Network

आधुनिक Blood Donor Network का responsive web app / PWA foundation.

## Roles
- 👤 User
- 🤝 Volunteer
- 🛡️ Admin

## Frontend
- React + Vite
- JavaScript
- Responsive / mobile-first UI
- PWA-ready structure
- Blood-themed premium red UI
- App-like mobile navigation
- Donor search & blood-group filters
- Blood request creation & management
- Volunteer case management
- Admin user/volunteer management
- Reports & analytics
- Secure chat UI
- Profile and settings screens

## Run locally
```bash
npm install
npm run dev
```

> अभी यह frontend/demo foundation है। Production phase में Node.js API + PostgreSQL, real authentication/OTP, Google Maps, FCM push notifications, realtime chat, image storage, verification workflow और secure role-based permissions connect किए जाएंगे.
